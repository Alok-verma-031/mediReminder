# 💊 MediReminder

MediReminder is a simple web application that helps users manage their medicine schedule and receive timely reminders so they never miss a dose.

---

## 📌 Problem

Many people, especially elderly patients and busy individuals, often forget to take their medicines on time. This can lead to health issues and improper treatment.

---

## 💡 Solution

MediReminder solves this problem by allowing users to:
- Add medicines easily
- Set time schedules for each medicine
- Get reminders to take medicines on time

---

## 🚀 Features

- Simple and user-friendly interface  
- Add and manage medicine schedules  
- Time-based reminders  
- Lightweight and fast web app  

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript
